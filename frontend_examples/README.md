# Quickstart Guide for Frontend Developers

## Getting Started

### 1. Clone the Repository
```bash
git clone <repository-url>
cd tel_u_shop/frontend_examples
```

### 2. Install Dependencies
```bash
npm install
```

### 3. Set Up Environment Variables
Create a `.env` file in the root directory and add the following:
```
REACT_APP_API_URL=http://127.0.0.1:8000/api
```

### 4. Run the Development Server
```bash
npm start
```

## Features

### Axios Client
- Centralized API client with token management.
- Located in `axios_client.ts`.

### Authentication Flow
- Login and registration examples.
- Located in `auth_flow.tsx`.

### Sample Component
- Example of fetching and displaying cart data.
- Located in `sample_component.tsx`.
